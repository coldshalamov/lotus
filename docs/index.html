Lotus 🪷

A density-reclaiming integer codec that maps every fixed-width bitstring into a contiguous range, then restores self-delimiting behavior with a bounded tier chain. Tune (J, d), hit start, and watch it trade blows with the varints as the value climbs.

configuration

Larger J = wider immediate width state but higher per-value header cost. Larger d = bigger maximum range via recursive width description.
