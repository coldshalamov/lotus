# Lotus 🪷

Lotus is a parametric bit-level integer codec for Rust. It maps every fixed-width bitstring onto a consecutive integer interval, then restores self-delimiting decoding with a bounded chain of positive width descriptors.

The repository now contains one canonical format definition, one codec implementation, one recommended configuration frontier, and generated evidence derived from that implementation.

> Open [`docs/index.html`](docs/index.html) for the interactive demo. It loads a Rust-generated boundary fixture and refuses to present itself as verified if the JavaScript port drifts.

## Canonical mapping

- Nonnegative payload width: `floor(log2(n + 2))`.
- Positive descriptor width: `floor(log2(v + 1))`.
- Codeword length: `J + sum(width chain)`.

See [`docs/FORMAT.md`](docs/FORMAT.md) for the normative wire layout.

## Recommended default

J1D2 is the minimum-bit profile covering all `u64` values.

```rust
use lotus::{LOTUS_DENSE_U64, lotus_decode_u64, lotus_encode_u64_framed};

let config = LOTUS_DENSE_U64;
let encoded = lotus_encode_u64_framed(
    42,
    config.jumpstarter_bits,
    config.tiers,
)?;

let (value, consumed) = lotus_decode_u64(
    &encoded.bytes,
    config.jumpstarter_bits,
    config.tiers,
)?;

assert_eq!(value, 42);
assert_eq!(consumed, encoded.bit_len);
# Ok::<(), lotus::LotusError>(())
```

For multiple values, use `BitWriter` and `BitReader` so codewords remain packed across byte boundaries.

## Recommended profile frontier

| profile | purpose |
|---|---|
| J1D1 | minimum overhead through 125 |
| J2D1 | one-tier density through `2^31 - 3` |
| J1D2 | minimum meaningful bits over full `u64` |
| J3D1 | one-tier full-`u64` traversal |

Arbitrary `(J,d)` values remain supported by the generic API, but dominated profiles are not promoted in the demo or benchmark evidence.

## Exact result against LEB128

Across every unsigned 32-bit integer, J1D2:

- wins on 4,058,104,710 values,
- ties on 33,686,546 values,
- loses on 203,176,040 values,
- wins strictly 94.485113% of the time.

These are exact interval aggregates generated by repository code. See [`docs/RESULTS.md`](docs/RESULTS.md).
